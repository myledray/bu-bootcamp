Activity Overview
You are going to build a program that reads a file of student scores, computes statistics, and writes a summary report. This is a complete, practical program. It uses every concept from this module: variables, types, control flow, methods, arrays, file reading, file writing, and exception handling. 

By the time you finish, you will have a program that does something genuinely useful, and you will have practiced the full development cycle: write, compile, test with good input, test with bad input, fix, and submit. 



What the Program Does 
Reads a text file called scores.txt, where each line contains one integer score (0 to 100). 
Calculates the average score, the highest score, and the lowest score. 
Counts how many scores fall into each grade band: A (90 and above), B (80 to 89), C (70 to 79), D (60 to 69), F (below 60). 
Handles empty files and invalid lines gracefully, printing a warning for each bad line instead of crashing. 
Writes a formatted summary report to a file called report.txt 
Prints the summary to the terminal as well.

Step 3: Implement readScores 
Use BufferedReader and a while loop to read the file line by line.  
For each line, call line.trim() first to remove whitespace.  
Skip blank lines (check if the trimmed line is empty with .isEmpty()).
Use Integer.parseInt inside a try-catch to parse each line.  
If parseInt throws NumberFormatException, print a warning and skip that line.  
Add valid scores to an ArrayList and return it when done. 
 

Step 4: Implement calculateAverage
If the scores list is empty, return 0.0 immediately.  
Otherwise, loop through all scores and accumulate the total in a double variable.  
Return the total divided by scores.size() 
Test this method by calling it from main with a small, hardcoded list before connecting it to the file reader. 
 

Step 5: Find the Highest and Lowest Scores
Write these directly in main (they do not need their own methods for this exercise).  
Initialize highest to Integer.MIN_VALUE and lowest to Integer.MAX_VALUE  
Loop through the scores list and update both as you go.  
 

Tip: Collections.max(scores) and Collections.min(scores) exist in java.util.Collections, but implement the loop manually this time to practice control flow. 

 

Step 6: Count the Grade Bands
Create 5 int counters: countA, countB, countC, countD, and countF, all starting at 0.  
Loop through the scores list once.  
Use if, else if, and else to assign each score to the correct band and increment the counter.  
Grade bands: A = 90+, B = 80 to 89, C = 70 to 79, D = 60 to 69, F = below 60. 
 
Step 7: Implement writeReport
